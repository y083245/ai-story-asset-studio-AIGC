Story Asset Studio 高质量风格包提示词模板
风格名称：真人电影级
风格 ID：live_action_cinematic
版本：2026-07-05
适用范围：小说文本解析后的角色图、场景图、道具图、角色三视图、图片质检、失败重试修复。

【项目适配说明】
本模板用于 Story Asset Studio 的 templates/style_packs，可被 character_library、scene_library、prop_library、image_asset、quality_retry 等模块读取。模板目标是把小说里的角色、场景、道具转成高质量静态视觉资产图，不包含分镜、视频、剪辑、时间轴等后续影视流程。

【占位符约定】
{project_title}：项目名
{novel_excerpt}：当前小说原文片段
{story_summary}：故事摘要或资产圣经摘要
{genre_id}：题材 id
{style_id}：风格 id
{aspect_ratio}：画幅比例，角色默认 9:16，场景默认 16:9，道具默认 1:1 或 4:3，三视图默认横版 16:9
{generation_mode}：生成模式，如角色正面全身图、角色半身情绪图、纯场景图、道具图、三视图设定板
{asset_name}：资产名称
{asset_aliases}：别名/代称
{novel_evidence}：原文证据，必须优先保留
{must_keep}：必须保持一致的锚点，如年龄、脸型、发型、衣服、核心道具、场景结构
{must_avoid}：必须避免的问题，如多人物、文字、水印、裁切、现代元素穿帮、风格跑偏
{quality_target}：质量目标，如高清、干净、材质准确、人物一致、适合资产库复用

【全局提示词拼装原则】
1. 证据优先：所有年龄、性别、身份、服装、场景、道具必须优先来自小说原文或资产圣经；原文缺失时，只能做符合题材和人物身份的合理补全。
2. 一致性优先：角色图、三视图、场景图、道具图必须共享同一套视觉锚点；同一角色的脸型、发色、发型、瞳色、身高比例、服装版型、关键配饰不能随意变化。
3. 主体清晰：角色图必须先写“人物主体”，再写五官、发型、服装、姿态、表情、镜头、光线、背景；场景图必须先写“环境类型”，再写时间、天气、空间层次、核心物件、光线；道具图必须先写“道具主体”，再写材质、形状、纹路、磨损、特效、摆放方式、背景。
4. 风格统一：不要在同一条生图提示词里同时堆叠互相冲突的风格，例如“真人写实 + 二次元平涂 + 粘土风 + 水彩”同时出现；本风格包内必须使用统一视觉语言。
5. 质量词精准：优先使用能指导画面的质量词，如“真实材质、体积光、轮廓光、景深、清晰轮廓、干净构图、材质细节、布料纹理、发丝层次”；少用空泛堆词。
6. 资产边界：只生成角色图、场景图、道具图、三视图设定板、质量修复提示词，不输出分镜、视频、剪辑、时间轴内容。
7. 输出可复制：所有 Prompt 模板都要能直接被 image_asset 的 prompt builder 拼装使用；不要把开发说明混进最终生图 Prompt。

【本风格核心定位】
面向都市、悬疑、现实情感、商战、复仇、年代、现代爽剧等写实题材。整体追求“真人电影剧照质感 + 真实摄影光线 + 可信服装材质 + 强情绪表演”，强调真实人物、真实皮肤、真实空间和故事感，不使用二次元/游戏CG语言。

【视觉关键词】
真人写实，电影剧照，真实皮肤纹理，毛孔，细微瑕疵，布料纤维，真实发丝，浅景深，窗光，实景光，轮廓光，伦勃朗光，胶片颗粒，低饱和高级色调，现实空间，人物情绪，故事感。

【色彩与光影规则】
根据题材选择冷暖：都市复仇偏冷灰蓝与暗部对比；爱情/家庭偏暖窗光与柔和肤色；悬疑偏低照度、窄光源和深阴影；商战偏冷白办公光与玻璃反射。禁止过度磨皮和夸张滤镜。

【材质与细节规则】
真实西装羊毛、衬衫棉质、真丝、皮革、粗花呢、牛仔、呢料、大衣、金属饰品、玻璃、木材、混凝土。服装必须有版型和质感，不能只写“高级衣服”。

【镜头与构图规则】
角色全身图用干净棚拍或真实环境留白；情绪图用近景/中近景、浅景深、眼神光；场景图用16:9电影实景；道具图用真实产品摄影。

【本风格禁忌】
避免动漫脸、AI塑料脸、过度美颜、皮肤无纹理、眼睛过大、虚幻引擎CG感、服装像cosplay、背景像影楼抠图、无意义超现实光效。
