# 真人电影级_3D动漫版｜Story Asset Studio 高质量提示词模板

版本：2026-07-06 最终补齐版
风格 ID：cinematic_live_action_3d_anime
文件用途：建议放入 `templates/style_packs/cinematic_live_action_3d_anime/`，作为角色、场景、道具、三视图、质检与失败重试的风格包模板。
适用项目边界：只服务“小说文本 → 视觉资产图”链路，不包含分镜、视频、剪辑、时间轴、配音、字幕等后续影视制作流程。

风格说明：这是“真人电影级”的 3D 动漫版，核心是电影镜头、真实材质、自然五官比例和高级光影，但输出仍是 3D 动漫 / CG 角色，不是真人照片。

【模块 00｜风格总纲】
============================================================

【一句话定位】
面向都市、悬疑、复仇、豪门、商战、现实剧情、犯罪调查等题材的电影级 3D 动漫资产图风格包。

【画面核心】
3D 动漫角色 + 真人电影级构图 + 写实布料材质 + 自然五官比例 + 情绪化光影。画面要像高预算真人电影的 CG 角色资产，而不是塑料脸动漫。

【人物核心气质】
男角色：沉稳霸总、复仇男主、警探、律师、商界精英、阴郁反派。女角色：清冷女主、豪门继承人、白月光、女律师、商业女强人、反派女配。共同要求：自然成熟、情绪真实、服装现代高级。

【色彩系统】
黑、白、灰、深蓝、驼色、酒红、米白、冷棕。整体低饱和，强调电影胶片感和真实服装质感。

【材质系统】
羊毛大衣、真丝衬衫、高定西装、皮革手包、金属腕表、钻石耳钉、磨砂眼镜、棉麻、风衣、呢料、皮鞋。

【光影系统】
电影级侧光、伦勃朗光、柔和棚拍光、窗边自然光、暗调轮廓光、浅景深背景虚化。角色资产图可用中性棚拍，情绪图可用电影暗光。

【镜头与构图】
角色资产图正面站立全身，纯白背景；特写图可用 85mm 人像镜头感、浅景深、面部聚焦；场景用 16:9 横版，真实空间透视。

【画质关键词】
3D动漫风格，真人电影级质感，自然五官比例，真实皮肤层次，非塑料脸，高级 CG 厚涂，电影级光影，真实布料纹理，发丝细腻，高清细节。

【必须避免】
避免真人照片、AI 塑料脸、过度美颜、网红滤镜、廉价短剧布景、五官夸张二次元化、肤色蜡像感、服装糊、过度磨皮。
